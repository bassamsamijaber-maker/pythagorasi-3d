    الدفع التجريبي داخل Classora

    الصفحة داخل موقعنا، ونموذج البطاقة الآمن يظهر من Paddle عند إدخال رمز Sandbox المخصص للواجهة.

    هذا الرمز من Client-side tokens، وليس API key سريًا. لا ترسل مفتاح API خاص بالخادم.

    Sandbox فقط: لا يتم سحب أموال حقيقية، ولا تتفعّل أي صلاحيات بالحساب من هذه الصفحة. يجب إضافة Firebase Webhooks آمنة قبل التشغيل الفعلي.
